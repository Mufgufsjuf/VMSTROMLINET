VMSTRØMLINET - hurtig start

1. Installer Node.js på værtscomputeren.
2. Åbn terminal/kommandoprompt i mappen vmstromlinet.
3. Kør:
   npm install
   npm start
4. Åbn siden i browseren på værtscomputeren:
   http://localhost:3000
5. Andre på samme netværk kan åbne siden via værtscomputerens lokale IP, fx:
   http://192.168.1.25:3000
